# Plano Aracruz 2026

Aplicativo Android offline do Plano Interativo de Estudos para a Câmara de Aracruz 2026.

Baixe o arquivo **Plano-Aracruz-2026.apk** na seção **Releases** deste repositório. Requer Android 8.0 ou superior.

O progresso fica salvo no dispositivo. Use a exportação de backup antes de limpar os dados ou desinstalar o aplicativo. Para trazer marcações da versão HTML, exporte o backup nela e importe no aplicativo.

Assinatura e integridade do APK verificadas. Ainda não testado em um aparelho Android real.
