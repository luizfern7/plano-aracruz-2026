# Plano Aracruz 2026

Aplicativo Android offline do Plano Interativo de Estudos para a Câmara de Aracruz 2026.

## Download

[Baixar Plano-Aracruz-2026.apk](https://raw.githubusercontent.com/luizfern7/plano-aracruz-2026/main/Plano-Aracruz-2026.apk)

Requer Android 8.0 ou superior. Abra o APK no celular e autorize a instalação pelo navegador quando solicitado.

O progresso fica salvo no dispositivo. Exporte um backup antes de limpar os dados ou desinstalar o aplicativo. Para trazer marcações da versão HTML, exporte o backup nela e importe no aplicativo.

Integridade do download e assinatura do APK verificadas. Ainda não testado em um aparelho Android real.
